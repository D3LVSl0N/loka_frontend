// Next.js Integration Guide

This file provides exactly what you requested: the terminal commands and the correct server-side structured code for **Next.js (App Router)** and **Prisma**. 

You can preview the live visual dashboard implementation in the preview panel (which uses a Next.js-style component structure, ported to work in this live environment).

### 1. Project Initialization Commands

Run these terminal commands sequentially to bootstrap your Next.js project with Tailwind CSS and Prisma.

```bash
# 1. Initialize Next.js with App Router and Tailwind
npx create-next-app@latest admin-dashboard \
  --typescript --tailwind --eslint \
  --app --src-dir --import-alias "@/*"

# Navigate into the directory
cd admin-dashboard

# 2. Install required icons and utilities
npm install lucide-react clsx tailwind-merge

# 3. Install Prisma and initialize it
npm install prisma --save-dev
npm install @prisma/client
npx prisma init
```

*Note: Configure your database connection string in the newly created `.env` file generated by Prisma.*

### 3. Server Node Logic (`src/lib/prisma.ts`)

Keep your database instantiation separate so you don't exhaust connection pools in development.

```typescript
import { PrismaClient } from '@prisma/client'

const prismaClientSingleton = () => {
  return new PrismaClient()
}

type PrismaClientSingleton = ReturnType<typeof prismaClientSingleton>

const globalForPrisma = globalThis as unknown as {
  prisma: PrismaClientSingleton | undefined
}

const prisma = globalForPrisma.prisma ?? prismaClientSingleton()

export default prisma

if (process.env.NODE_ENV !== 'production') globalForPrisma.prisma = prisma
```

### 5. Page Code with Prisma Data Fetching (`src/app/page.tsx`)

This is a Next.js Server Component. It connects directly to Prisma securely on the server and passes the fetched payload to your interactive Client Component table.

```tsx
import prisma from '@/lib/prisma';
import UserTable from '@/components/UserTable';
// Assume you have an auth utility to get the session role
import { getUserSession } from '@/lib/auth'; 

export const dynamic = 'force-dynamic'; // Prevent caching for live admin data

export default async function UsersPage() {
  // 1. Secure Database Data Fetch via Prisma
  const users = await prisma.user.findMany({
    select: {
      id: true,
      name: true,
      email: true,
      role: true,
      status: true,
    },
    orderBy: { createdAt: 'desc' }
  });

  // 2. Fetch the current logged-in user's session role (e.g., via NextAuth)
  const session = await getUserSession();
  const currentUserRole = session?.role || 'Admin';

  return (
    <>
      <header className="bg-white border-b border-slate-200 px-8 py-5">
        <h1 className="text-2xl font-semibold text-slate-800">User Management</h1>
        <p className="text-slate-500 text-sm mt-1">Manage system administrators and operator access.</p>
      </header>
      
      <div className="p-8 flex-1 overflow-y-auto">
         {/* Pass server-fetched data and securely fetched role to the Client UI */}
         <UserTable initialUsers={users} currentUserRole={currentUserRole} />
      </div>
    </>
  );
}
```

### 6. Secure Server Action (`src/app/actions.ts`)

To ensure **secure server-side role validation** when deleting a user (so they can't just bypass the UI hidden buttons), define a Next.js Server Action:

```typescript
'use server'

import prisma from '@/lib/prisma';
import { getUserSession } from '@/lib/auth';
import { revalidatePath } from 'next/cache';

export async function deleteUserAction(userId: number) {
  // 1. Re-validate role securely on the server
  const session = await getUserSession();
  
  if (session?.role !== 'Superadmin') {
    throw new Error('Unauthorized: Only Superadmins can delete users.');
  }

  // 2. Safely perform Prisma deletion
  await prisma.user.delete({
    where: { id: userId }
  });

  // 3. Clear Next.js cache for the layout so the table updates
  revalidatePath('/');
}
```

*(You would import this Server Action into the `UserTable` Client Component to hook up to the delete button).*
