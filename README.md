# LivestockGuard Enterprise Admin Portal

**GitHub Description:** A secure, role-based enterprise administration dashboard for livestock monitoring and IoT IoT field operator management.

## Features Summary

- **Role-Based Access Control (RBAC):** Distinct privileges for standard Operators, basic Admins, and a strictly enforced single Super Admin.
- **Authentication Interface:** Secure login simulation tailored for "Earth-First Security" agricultural operations.
- **User Management Operations:** Full CRUD interface for managing active field personnel and enterprise administrators.
- **System Settings:** Centralized hub for profile administration, notification preferences, security credential updates, and API Key lifecycle management.
- **Security & Activity Reporting:** Real-time online administrator tracking, critical security alerting, and comprehensive user activity audit logs.

## 🚀 Team Developer Guide

Everything you need to take this local prototype to a production-ready application.

### 1. Opening in VS Code
1. Unzip the downloaded project folder.
2. Open your terminal or command prompt.
3. Navigate into the unzipped folder: `cd path/to/unzipped-folder`
4. Type `code .` to open the directory directly in VS Code.
5. Open the integrated terminal in VS Code (`Ctrl` + `~`).
6. Run `npm install` to ensure all dependencies are ready.
7. Run `npm run dev` to start the local development server.

### 2. Version Control (Pushing to GitHub)
To version control this project, run the following commands sequentially in your VS Code terminal:

```bash
git init
git add .
git commit -m "Initial commit: LivestockGuard Admin Dashboard"
git branch -M main
```

Next, go to GitHub, create a new empty repository, copy its HTTPS/SSH URL, and run:
```bash
git remote add origin <YOUR_GITHUB_REPO_URL>
git push -u origin main
```

### 3. Connecting a Real Database

Right now, the application uses an Express server (`server.ts`) with an in-memory mock JSON array (`let users = [...]`) to simulate database transactions. Your backend engineers can easily swap this out for a real database (PostgreSQL, MySQL, etc.).

**Implementation Steps:**
1. **Choose an ORM (e.g., Prisma):**
   ```bash
   npm install prisma --save-dev
   npm install @prisma/client
   npx prisma init
   ```
2. **Configure your Database URL:** Update the `.env` file generated by Prisma with your actual database connection string.
3. **Migrate `server.ts`:** Locate the Express API endpoints in `server.ts` (like `app.get('/api/users')` or `app.post('/api/users')`). Replace the mock array manipulation with real database queries (e.g., `await prisma.user.findMany()`).
4. **Implement Real Security:** Replace the `x-mock-role` header logic in the `authenticateRole` middleware with a real JWT (JSON Web Token) or session validation library.

### 4. What are the API Keys for?
In the settings panel, you'll see an "API Keys" section. 
API keys are secure, non-human passwords. They allow external systems—like **IoT smart collars on your livestock, automated weather stations, drones, or third-party farming software**—to send automated data to your database without needing to manually log in through the application interface.
